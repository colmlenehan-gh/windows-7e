# Windows 7e design principles

The design goal is to deliver a modern Linux desktop with a strong Windows 7 identity without visibly degrading system correctness or security.

## Primary objective

The user should immediately recognize the desktop and workflow without needing to relearn basic navigation.

## What matters most

- familiar taskbar and Start menu patterns
- iconic desktop semantics and file explorer conventions
- subtle Aero-like polish in title bars and surfaces
- modern system safety underneath the nostalgic layout

## Non-goals

- a fake browser mock-up
- a static screenshot-only project
- a Linux skin that does not provide real OS functionality

## Release criteria

The release will only be considered complete when a real build, install, and smoke validation are demonstrated in a VM environment.
