# Licensing and asset policy

## Source code

The project uses open-source upstream licenses where possible. The repository default license is MIT unless a component specifically requires another legal path.

## Assets

All branding and visual assets must be:

- original, or
- under a compatible license, or
- replaced with a legally distinct Windows 7–inspired design that does not reuse Microsoft-protected assets

## Compatibility components

Wine, DXVK, VKD3D-Proton, Mesa, and related compatibility components are developed under open-source licensing and are accepted in a Linux distribution project when used under their licensing terms.

## Caution

The project must avoid redistributing proprietary Microsoft binaries, Windows icon sets, or copyrighted component assets without clear rights.
