# Windows 7e themes

The theme system is expected to deliver a Windows 7–inspired visual language while respecting open-source licensing and modern Linux rendering.

## Art direction

- glass and translucency in the taskbar and dialogs
- subtle Aero-like gradient surfaces
- classic icon geometry and desktop spacing patterns
- extended color palette tuned for Windows 7 nostalgia
- theme switching and low-resource fallback mode

## Asset handling

All visuals must be:

- original or licensed
- consistent with the project identity
- stored with metadata and licensing status

## Current state

This directory provides the design structure and engineering plan. Final theme assets will be generated once the base live image is validated.
